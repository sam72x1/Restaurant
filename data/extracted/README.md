# السجلات المستخرجة

الأرقام فقط تُحفظ هنا؛ المستندات الأصلية مستثناة في `.gitignore`.

| الملف | المحتوى |
|---|---|
| `ledger.csv` | الدفعة الأولى — 126 مستندًا (أبريل–سبتمبر 2026) |
| `shifts.csv` | تقارير صندوق البيع اليومية من نظام رواء |
| `purchases.csv` | فواتير الموردين على مستوى الصنف |

## shifts.csv

`img,فتح,إغلاق,أيام,المبيعات,الكمية,عمليات_البيع,الضريبة,نقد_متوقع,نقد_مدخل,شبكة_متوقع,شبكة_مدخل,rewaa_pay,ملاحظة`

الوردية قد تمتد أكثر من يوم — عمود `أيام` يحمل عدد الأيام التقويمية
بين الفتح والإغلاق، وتُقسَّم عليه المبيعات لاستخراج المعدل اليومي.
