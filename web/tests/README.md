# اختبارات بوابة الرفع

تُشغَّل بمتصفح حقيقي (Chromium عبر Playwright) مع بديل مزيّف لقاعدة
البيانات والتخزين، فتقيس سلوك الصفحة نفسه لا افتراضات عنه.

```bash
node web/tests/realtest.js  /home/user/Restaurant/web/upload-portal.html 139
node web/tests/upload-test.js     # المسار الطبيعي من الاختيار حتى الاكتمال
node web/tests/dedupe-test.js     # إعادة اختيار نفس الملف لا تُنشئ نسخة ثانية
node web/tests/hang-test.js       # عملية لا تنتهي أبدًا يُفلتها المؤقت ويكتمل الرفع
node web/tests/suspend-test.js    # المهلة تتوقف حين تغادر الصفحة وتستأنف عند العودة
```

`realtest.js` يحتاج صورًا بحجم صور الجوال في `bigs/`؛ ولّد واحدة بحجم
4032×3024 ونسخها بالعدد المطلوب.

## الدرس

كل اختبارات الجولات الخمس الأولى كانت بستة ملفات أو أقل، وثلاثة من
أخطر الأعطال — تحرير قفل الإيقاظ بعد أول ملف، والوعود بلا مهلة،
والبناء التربيعي للعرض — لا تظهر إطلاقًا في ذلك النطاق. **اختبر عند
الحجم الحقيقي، لا عند حجم مريح.**

## عطل التوقّف التام عند 203 ملفات — 2026-09-12

**ما ظهر للمستخدم:** ملفان يبقيان «جارٍ الرفع» بلا نهاية، والدفعة كلها تقف.

**ما أثبته سجل التدقيق الدائم:**

```
pick_open   09:03:33
delivered   09:04:28 — 203 ملفات · 495 م.ب
```

النظام سلّم الـ203 كاملة. الخلل كله بعد التسليم.

**ثلاثة عيوب متراكبة:**

1. `withTimeout` يعدّ الزمن الظاهر فقط (إصلاح تجميد iOS). حين يُجمّد
   النظام الصفحة يتوقف عدّاده، فلا تُفلت العملية المعلّقة أبدًا.
2. `sweepStalled` كان يستثني الصفوف النشطة صراحةً:
   `if(r.status !== "uploading" || active[r.id]) return;`
   فهو ينقذ ما يتيه بإعادة تحميل الصفحة، ولا ينقذ مسارًا معلّقًا.
3. `laneCount = 2`. ملفان معلّقان = مساران ميتان = الدفعة كلها تتوقف.
   لا مشرف فوق المسارات.

**السبب المرجّح للتعليق نفسه:** 203 مرجع ملف محجوزة (نحو 500 م.ب)
مع فك ترميز صورتين بـ12 ميجابكسل. تحت ضغط الذاكرة يبقى
`createImageBitmap` معلّقًا بلا حلٍّ ولا رفض.

**الإصلاح — بنيويّ لا علاجيّ:**

- `withDeadline` بساعة الحائط (150 ثانية) حول مسار الملف كاملًا، لا
  تعتمد على ظهور الصفحة. المسار يتقدّم مهما حدث لملف واحد.
- `sweepStalled` يلتقط الصف النشط أيضًا بعد تجاوز المهلة المطلقة.
- `files[idx] = null` بعد كل ملف لإفلات المرجع.
- `file_deadline` في السجل الدائم لكل تجاوز.

**الدرس:** كل إصلاح يضيف حالة، وكل حالة تحتاج مخرجًا. مهلةٌ مشروطة
بظهور الصفحة ليست مهلة — هي تأجيل. ولا يكفي أن يكون لكل عملية مهلة:
يجب أن يكون فوق المسارات مَن يضمن تقدّمها.
