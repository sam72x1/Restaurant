# دراسة جدوى — استحواذ على مطعم قائم

هذا المستودع هو ملف العمل الكامل لصفقة شراء مطعم قائم: الفحص النافي للجهالة،
التحقق من أرقام البائع، النموذج المالي، وتقييم السعر العادل.

## المبدأ الحاكم
> **لا يدخل أي رقم في هذه الدراسة بدون مستند يُثبته.**
> أرقام البائع الشفهية تُسجَّل كـ «ادّعاء» حتى تُطابَق مع مستند مستقل.

كل رقم في النموذج مصنّف إلى:

| التصنيف | المعنى |
|---|---|
| `verified` | مثبت بمستند مستقل (تقرير نقاط بيع + كشف بنكي + إقرار ضريبي) |
| `claimed` | ادّعاء من البائع بدون إثبات — لا يُعتمد في القرار |
| `estimated` | تقدير من معايير القطاع — يُستخدم للحساسية فقط |
| `missing` | ناقص — يوقف الحساب |

## الهيكل

```
data/
  invoices/      فواتير المشتريات والموردين (أهم مصدر للتحقق من التكلفة)
  pos-reports/   تقارير نقاط البيع (Z-Reports) — التحقق من الإيرادات
  bank/          كشوف حسابات بنكية / تقارير مدى — التحقق من التحصيل الفعلي
  contracts/     عقد الإيجار، عقد التنازل، عقود الموردين، عقود العمالة
  licenses/      الرخص: البلدية، السجل التجاري، السلامة، الصحية، اللوحة
docs/
  00-data-request.md            قائمة المستندات المطلوبة منك (ابدأ من هنا)
  01-due-diligence.md           قائمة الفحص النافي للجهالة
  02-red-flags.md               مؤشرات الخطر التي توقف الصفقة
model/
  inputs.json        مدخلات النموذج (تُملأ من المستندات فقط)
  feasibility.py     محرك النموذج المالي
reports/             المخرجات: الدراسة، التقييم، تحليل الحساسية
```

## التشغيل

```bash
python3 model/feasibility.py --inputs model/inputs.json --out reports/
```

المحرك يرفض الحساب إذا كانت مدخلات حرجة ناقصة، ويُظهر بوضوح ما يعتمد على
`claimed` بدل `verified`.
